# 香港市場 eSIM UI 設計排版稿

## 1. 頁面定位

以現有日本 eSIM 詳情頁為基礎，改成可以支援多個旅遊目的地的香港市場產品頁：

- 主要市場：中國內地、泰國、韓國、台灣
- 主要語言：香港繁體中文
- 主要行動：選擇地區 → 選擇流量／天數 → 查看 HKD 價格 → 立即購買
- 核心賣點：即時收 QR Code、免換實體卡、香港 WhatsApp 客服

## 4. 市場切換設計

導航列及 Hero 上方加入市場選擇器：

```text
[中國內地] [泰國] [韓國] [台灣]
```

互動規則：

1. 點擊市場後切換圖片、商品標題及商品資料。
2. 只顯示該市場已選定的上架產品系列。
3. 預設顯示價格最低的可購方案。
4. 切換方案時同步更新價格、天數、流量及付款連結。
5. 手機版市場選擇器可以橫向滑動。

## 6. 商品卡片內容規格

每張方案卡只顯示用戶最需要的資訊：

```text
每日 2GB
高速流量後按方案降速

1日｜3日｜5日｜7日｜10日｜15日｜20日｜30日

HK$XX 起
[ 選擇方案 ]
```

不要在第一屏放入過長供應商名稱；供應商名稱可放在「方案詳情」或 FAQ 內。

## 8. 文字語氣

- 使用香港繁體中文及香港常用詞：`落單`、`到埗`、`上網`、`短訊`、`客服`
- 避免使用供應商內部名稱作為主標題。
- 先講用戶利益，再講技術規格。
- 所有方案都清楚寫明：有效日數、流量規則、啟用時間、是否有電話／SMS。

## 9. 必備注意事項

```text
購買前請確認：
1. 手機支援 eSIM，並可查看 EID。
2. 手機沒有被電訊商鎖定。
3. eSIM 安裝需要穩定 Wi-Fi。
4. 啟用方式及有效期按個別方案說明為準。
5. 大部分旅遊 eSIM 為 Data Only，不包括本地電話號碼及 SMS。
```

## 10. 視覺方向

- 保留現有：螢光黃公告列、綠色購買按鈕、白色卡片、圓角及柔和陰影。
- 市場色彩只用於圖片及小型 badge，不改變整個品牌色系。
- Desktop 使用左右雙欄；Mobile 改為單欄及固定底部 CTA。
- 所有價格以 HKD 顯示，使用整數及 `HK$` 前綴。
