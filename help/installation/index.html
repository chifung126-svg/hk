INSTALLATION AND ACTIVATION

如何安裝及啟用 eSIM？

一般做法是出發前在穩定 Wi-Fi 下加入 eSIM，抵達目的地後才切換流動數據。個別產品以訂單電郵及產品頁為準。

iPhone 安裝步驟

  1. 開啟「設定」，進入「流動網絡／流動數據」。
  2. 選擇「加入 eSIM」或「加入流動方案」。
  3. 選擇使用二維碼，掃描訂單電郵中的 QR Code。
  4. 完成加入後，將新線路命名為 EasyGoSIM 或目的地名稱。
  5. 如產品指示抵達後才啟用，出發前只確認已加入，不要提早切換數據。

Android 安裝步驟

  1. Samsung：進入「設定 → 連接 → SIM 卡管理員」；其他 Android：進入「設定 → 網絡與互聯網 → SIM」或相近選項。
  2. 選擇「新增 eSIM」、「加入流動方案」或「下載 SIM」。
  3. 掃描 QR Code，按畫面確認下載及加入。
  4. 完成後為線路命名，方便抵達後辨認。
  5. 如產品指示抵達後才啟用，可先把 EasyGoSIM 線路關閉。
同一 QR Code 通常只供一部手機安裝一次。安裝失敗時不要刪除 eSIM，先聯絡客服。

抵達目的地後如何啟用？

  1. 開啟 EasyGoSIM eSIM 線路。
  2. 將「流動數據／行動數據」選為 EasyGoSIM。
  3. 按選定產品說明開啟數據漫遊。
  4. 關閉香港主卡的數據漫遊及數據自動切換。
  5. 開關飛行模式一次，等候手機連接網絡，再用瀏覽器或地圖測試。
設定項目建議處理
香港 SIM可按需要保留接收電話或短訊；關閉其數據漫遊。
流動數據選擇 EasyGoSIM eSIM，避免使用香港主卡數據。
數據漫遊只按產品說明在 EasyGoSIM 線路設定。
啟用日數按產品頁及訂單電郵的開始計算規則為準。
