# EasyGoSIM 產品頁 UI 統一規格

> 版本：2026-08-24  
> 唯一樣版：`/jpesim/` 日本 eSIM 產品頁  
> 適用：所有國家、多地及跨境 eSIM 產品頁

## 1. 核心原則

所有產品頁必須跟隨日本頁的版面、間距、按鈕、手機操作及內容層級。每個產品只可以更換相應的國家資料，不可以自行建立另一套 UI。

保留各產品自己的：

- 國家／地區名稱及旗幟
- Hero 圖片、網絡名稱及覆蓋範圍
- 流量、日數、速度及限制
- SKU、價格、優惠碼及結帳連結
- 國家專屬 FAQ、安裝說明及 SEO 內容

不得交叉顯示其他國家的產品名稱、圖片、網絡、價格或安裝說明。

## 2. 固定頁面結構

產品頁順序固定如下：

1. 黃色促銷提示列
2. Sticky Header：EasyGoSIM Logo、產品頁導覽、WhatsApp 客服
3. Hero／產品選擇區
   - 左側：國家視覺圖、網絡 badge、產品短句
   - 右側：旗幟、產品名稱、最低價格、信任標籤、套餐選擇器
   - 方案分類按鈕
   - 日數按鈕
   - 已選方案資料及價格
   - 綠色「立即購買」按鈕
4. 手機固定購買列
5. QR Code、客服、保留香港 SIM 等信任資訊
6. 產品優勢
7. 安裝步驟
8. 網絡／覆蓋資料
9. 手機支援及 FAQ
10. 已驗證會員評論
11. SEO 指南內容（可折疊）
12. Footer 及政策連結

評論區必須放在 FAQ 之後，不能因 Flex 排序或動態插入而跑到頁面前方。

## 3. 元件規格

### Header

- 必須使用正式 EasyGoSIM Logo，不使用地球圖示或文字代替 Logo。
- 桌面版保持日本頁導覽風格。
- 手機版保留 Logo、Help／SEO、會員入口及客服／選單操作。
- 所有可按範圍至少 44px 高。

### 方案及日數按鈕

- 未選狀態：白色背景、灰色邊框。
- Hover／Focus：綠色邊框。
- 已選狀態：`#edfff7` 淡綠背景、`#13ad61` 綠色邊框及深綠文字。
- 不同產品可有不同按鈕數量，但不得更換按鈕形狀或狀態規則。
- 每次只可以有一個方案及一個日數為 active。

### 立即購買

- 統一使用 EasyGoSIM 綠色主按鈕。
- 桌面版最小高度 58px。
- 手機版最小高度 52px，並放入固定底部購買列。
- 文字統一為「立即購買」。
- 必須連到相應 SKU，不得寫死日本 SKU。

### 評論區

- 標題固定為「已驗證會員評論」。
- 顯示大評分，例如 `★ 4.5` 及評論數量。
- 顯示「由已完成付款會員評價」等驗證狀態。
- 評論內容必須按產品／SKU 對應，不能把日本評論顯示到其他產品頁。
- 評論區置於 FAQ 之後。

## 4. 手機版規則

- 以 390px 寬度作主要檢查基準，並兼容 320–430px。
- Hero 圖片、方案卡及文字不可溢出畫面。
- 方案／日數按鈕可橫向滑動或自動換行，但不可被底部購買列遮住。
- 頁面底部必須預留固定購買列高度。
- 內容左右留白約 14–18px。
- 不使用過小於 10px 的主要操作文字。
- 所有按鈕、連結及卡片的點擊範圍至少 44px。

## 5. SEO 及內容規則

- 每頁只保留一個主要 H1，內容必須對應該國家／地區。
- `title`、description、canonical、OG 內容必須與產品頁一致。
- SEO 長文放在頁面後段或 `/blog/`、`/help/`，不可壓過產品選購區。
- Help／SEO 導覽統一連到 `/blog/`、`/help/`、`/setup/` 及對應文章。
- 發現 404 必須修正連結或建立相應頁面，不可保留死鏈。

## 6. 開發及部署檢查

新增產品頁時必須完成：

1. 套用 `body.egs-japan-template` 及共用產品 CSS。
2. 確認該頁所有產品內容與 SKU 對應正確。
3. 檢查桌面版及 390px 手機版。
4. 測試方案、日數及立即購買連結。
5. 檢查手機固定購買列不遮住按鈕。
6. 檢查評論、FAQ、SEO 連結及 Footer。
7. `git diff --check` 及 checkout smoke test 通過後才部署。
8. 只提交本次相關檔案，不能把其他對話區未確認的改動一併部署。

## 7. 禁止事項

- 不得再以 Tripma 或其他外部網站取代日本頁作樣版。
- 不得為單一國家另做一套按鈕、Header 或手機購買列。
- 不得把中國、港澳、日本或其他產品資料交叉顯示。
- 不得把 SEO 文案放到首屏而令客人難以選購。
- 不得未檢查正式資料庫、SKU 及結帳連結便部署。
